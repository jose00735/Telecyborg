# 08 — Content packs (planned, v0.3)

A content pack is everything for one occasion — an interview, a QBR, a demo — in one folder:

```
packs/terrific-interview/
├── pack.md          the brief you fill in (topics, audience, sources, length)
├── claude-brief.md  generated by TeleCyborg: the prompt to give Claude
├── script.md        imported from Claude: the main pitch (sections + keywords)
└── qa.md            imported from Claude: likely questions and answers (sections + keywords)
```

## Requirements
| ID | Requirement | P |
|---|---|---|
| CP-1 | New pack form: occasion type (interview, customer meeting, demo), audience, goal, length, language, topics (list), must-mention facts, things to avoid, sources (links or pasted text). | M |
| CP-2 | "Generate brief" writes `claude-brief.md`: role, audience, goal, timing (words per section from the target time), facts, sources, and the exact output format below. | M |
| CP-3 | One-click copy of the brief; open claude.ai in the browser. | M |
| CP-4 | Import Claude's answer by paste; validate the format and show what will be created. | M |
| CP-5 | Pitch and Q&A become scripts linked to the pack; Q&A sections become cue targets (stage 2). | M |
| CP-6 | Packs can be exported as a zip and imported on another machine. | S |

## Output format requested from Claude
```markdown
---
title: <pitch title>
target: <m:ss>
---
# <Section title>
keywords: <comma-separated words a listener would say that should trigger this section>
<paragraphs>

=== QA ===
# Q: <likely question>
keywords: <...>
<answer paragraphs, ≤ 60 seconds>
```

## Facts discipline
The brief tells Claude to use only the facts and sources provided, never to invent metrics, and
to mark anything it is unsure of with `[check]`, which TeleCyborg highlights in the editor.
